# 平台删除能力 · 分批执行计划（2026-11-20）

## 1. 背景与准入范式

管理台多数"添加类"实体此前只做启用/禁用或归档，不支持删除；现场长期运行会积累误添加的无效内容，占用登记数据与落盘存储。经全仓盘点（2026-11-20）定案如下准入范式：

- **状态门控**：仅"已归档 / 已停用 / 已过期 / 已作废"的内容允许删除；在用状态一律 409 拒绝，先退役再删。
- **引用门控**：删除前必须无下游引用（FK 子行、跨模块软引用按 key 扫描）；涉内容寻址 blob 的一律复用 `VersionBlobReclaim`（sha 跨 ReleaseFile/ReleasePackage/AppUpdaterRelease/DriverMedia 四类登记行判引用，无引用才删源与 `{sha}.zip` 派生缓存）。
- **留痕不删**：审计、会话、投递记录、验签密钥等留痕/安全态数据永久不提供删除入口，只靠既有清理任务限长。
- **并发语义**：删除后在途请求得到业务 404（而非 500）；所有登记"软删行+唯一约束"模式在删除后重建同键不受阻。
- **权限**：本轮全部复用各模块既有 `*.manage` / 专用管理码，不新增权限码（删除即管理动作的一部分）。

已完成先例：版本删除 `DELETE /releases/{id}`（`15d1633`）、更新器删除 `DELETE /updaters/{id}`（`2e67b5c`，复用 `versions.release.delete`）。

## 2. 分类结论

### A 类 · 补守卫即可给删除（第一批）

| 实体 | 现状 | 删除条件 | 权限 |
|---|---|---|---|
| 发布渠道 ReleaseChannel | 仅启停；FK 到版本是 Cascade（暗雷：删渠道会连删版本树） | 渠道下无任何版本（含草稿/归档）才可删 | `versions.channel.manage` |
| 授权产品 LicenseProduct | 仅启停 | 无授权实例与离线码引用 ProductId | `license.product.manage` |
| 文档集合 DocumentCollection | 无删除 | 集合为空（含软删文档）才可删 | 集合管理码（沿用 update 同码） |
| 备份空间 BackupNamespace | 无删除 | 空间内无任何备份记录（含软删）才可删 | `backup.namespace.manage` |

### 现存"无守卫删除"缺陷（第一批一并修）

| 实体 | 缺陷 | 修复决定 |
|---|---|---|
| Webhook 订阅 | DELETE 无状态门控，且连带硬删投递记录 | 已启用拒删；存在未终结（pending/queued）投递拒删；订阅退役后其投递记录随删（投递留痕本就由清理任务限长，订阅没了留痕无上下文） |
| 离线授权码 OfflineLicenseCode | DELETE 无状态门控 | 仅已过期（`NotAfter < now`）可删；有效码拒绝（仍可被客户端验签使用，作废走吊销产品/实例链路） |
| 驱动媒体 DriverMedia | DELETE 可删启用行且不回收 blob | 启用中拒删（先禁用）；删行后按 `VersionBlobReclaim` 同口径回收；`mediaRequirements` 是 mediaKey+componentId 字符串软引用，删到无启用行时组合下载自然按既有"缺项"语义报错 |

### B 类 · 需引用守卫/级联设计（第二批）

| 实体 | 引用方 | 建议条件 |
|---|---|---|
| 设备节点 DeviceNode | Installation FK Restrict；MachineCode 被许可/令牌软引用 | 离线 + 无子安装实例 |
| 安装实例 DeviceInstallation | RefreshToken / Backup.InstallationId / QrSession 软引用 | 在线必须拒删；级联清理令牌与备份归属 |
| Webhook 订阅（升级路径） | — | 第一批已给基础守卫，第二批再评估留痕保留策略 |
| AppApiKey | 凭据审计 | 仅限已撤销且过期行 |
| 授权实例 LicenseEntitlement | 台账 | 倾向永久只停用+吊销留痕，不删除 |

### C 类 · 永久只做启停/留痕，不给删除

应用 App（AppKey 是全模块隔离轴）；权限码/预设（被角色授权引用，已有 lock/整表替换机制）；会话与刷新令牌、扫码会话；Webhook 投递记录；验签密钥（旧离线码长期验签需公钥，retire 即终态）；审计日志；登录限流记录。

## 3. 分批范围

**第一批（本轮，已落地）**：§2 "现存无守卫删除"三项守卫 + A 类四组删除端点（含前端入口、集成测试、接口文档同步）；顺手优化：驱动媒体列表 `mediaKey` 筛选由精确匹配改为 `EF.Functions.Like` 模糊包含（对齐备份/文档搜索既有写法），管理台占位文案同步。

落地口径（错误码：versions 段内复用 `222 VersionsReleaseImmutable`，段外一律通用 `6 Conflict`，都映射 HTTP 409）：

| 项 | 端点 | 守卫 | 回收 |
|---|---|---|---|
| 驱动媒体 | `DELETE /admin/versions/media/{id}`（原有） | `IsActive` 拒删（先激活同键其它版本） | 删行后 `VersionBlobReclaim` |
| Webhook 订阅 | `DELETE /admin/webhooks/{id}`（原有） | `IsEnabled` 拒删；存在 `pending`/`failed` 投递拒删 | 终结态投递记录随订阅删除 |
| 离线授权码 | `DELETE /admin/licensing/offline-codes/{id}`（原有） | `NotAfter + GraceDays >= now` 拒删（码无法吊销，未过期须留痕） | 无落盘内容 |
| 发布渠道 | `DELETE /admin/versions/channels/{id}`（新增，`versions.channel.manage`） | 渠道下存在任何版本（含草稿）拒删；不存在 `200` | 无 |
| 授权产品 | `DELETE /admin/licensing/products/{id}`（新增，`license.product.manage`） | 存在授权行或离线码台账拒删；不存在 `300` | 无 |
| 文档集合 | `DELETE /admin/documents/collections/{id}`（新增，`document.collection.manage`） | 存在文档行（含软删待清理）拒删；不存在 `500` | 内容随文档既有清理链路 |
| 备份命名空间 | `DELETE /admin/backups/namespaces/{id}`（新增，`backup.namespace.manage`） | 存在备份行（含软删待清理）拒删；不存在 `400` | 内容随备份既有清理链路 |

对应测试：`渠道删除按版本留痕受控`、`产品删除按授权与离线码留痕受控`、`集合删除按文档留痕受控`、
`命名空间删除按备份留痕受控`、`登记媒体包后可下载激活互斥并可删除`（含模糊筛选断言）、
`WebhooksAndAuditEndpointsTests`（启用拒删后停用再删）、`离线码绑定机器与产品且跨机器误用被拒`
（未过期拒删 + 过期行可删）。管理台入口分别在版本·渠道页签、授权·产品表、文档·集合表、备份·命名空间表、
更新器与驱动媒体表；Webhook 删除确认文案已注明两道门。

**第二批**：B 类（设备域守卫最复杂，需先定在线判定与令牌级联语义）。

**不在计划**：C 类一律不加删除入口；SingleLoginKey 未核销撤销并入第二批评估（一次性口令本有 TTL，风险低）。

## 4. 验证与提交约定

每批完成后：`dotnet build Platform.slnx -c Release --disable-build-servers` → `dotnet test`（独立调用）→ web `npm run verify` → 格式门（.cs CRLF 无 BOM）→ 本地提交；受影响旧测试按新语义直接改写（零兼容期，不加开关）。
